## Goal

You are helping draft or update a **feature contract** (`contract.yaml`) for a single feature in the `specdrive` project.

1. Read all referenced local files in full **before** writing anything.
2. Treat the feature spec + contract template + project constitution + relevant ADRs as the source of truth.
3. Produce a **single `contract.yaml`** that:
   - Follows the existing contract schema (same shape as the templates in `docs/templates/`).
   - Accurately reflects the behaviour, constraints, and impact described in the feature spec.
   - Is consistent with the project Constitution and relevant ADRs.

Do **not** modify specs, existing contracts, the constitution, or ADRs. You are only drafting the *contents* of a new or updated `contract.yaml`.
